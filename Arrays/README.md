# Arrays

## 📌 Overview
Arrays store elements of the same data type in contiguous memory locations. Understanding array manipulation, sub-arrays, prefix sums, and searching/sorting algorithms forms the bedrock of problem-solving.

## 🛠️ Common Patterns & Techniques
- Two Pointers / Sliding Window
- Prefix Sum / Difference Array
- In-place Traversal & Swapping
- Kadane's Algorithm (Max Subarray Sum)
- Dutch National Flag Algorithm (3-way partitioning)
