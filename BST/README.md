# BST (Binary Search Tree)

## 📌 Overview
A Binary Search Tree is a binary tree where the left subtree contains values smaller than the root, and the right subtree contains values larger than the root.

## 🛠️ Common Patterns & Techniques
- Search, Insert, and Delete operations in \(O(\log N)\) average time
- In-order Traversal yielding sorted output
- Validating BST properties
- Converting BST to sorted Doubly Linked List / Array
