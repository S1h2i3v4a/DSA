# Backtracking

## 📌 Overview
Backtracking is an algorithmic technique for solving problems recursively by trying to build a solution incrementally, removing solutions that fail to satisfy constraints.

## 🛠️ Common Patterns & Techniques
- State Space Tree exploration
- Subsets, Combinations, and Permutations
- Constraint Checking & Pruning (e.g., Sudoku, N-Queens)
- Decision Tree Branching with undoing steps (backtrack)
