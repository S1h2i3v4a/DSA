# Binary Search

## 📌 Overview
Binary Search cuts the search space in half at each step, achieving \(O(\log N)\) time complexity on sorted structures or monotonous search spaces.

## 🛠️ Common Patterns & Techniques
- Search on Sorted Array
- Binary Search on Answer Space (Minimizing/Maximizing feasible results)
- Finding First/Last occurrence (Lower/Upper Bound)
- Rotated Sorted Array Searching
