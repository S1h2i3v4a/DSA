# Dynamic Programming

## 📌 Overview
Dynamic Programming (DP) optimizes recursive solutions by breaking problems into overlapping subproblems and storing intermediate results to avoid redundant work.

## 🛠️ Common Patterns & Techniques
- Top-Down Memoization vs Bottom-Up Tabulation
- 1D DP (Fibonacci, Climbing Stairs, House Robber)
- 2D / Grid DP (Unique Paths, Minimum Path Sum)
- Knapsack Problems (0/1 Knapsack, Unbounded Knapsack)
- Subsequence / String Alignment DP (LCS, LIS, Edit Distance)
- State Optimization & Space Reduction
