# Graph

## 📌 Overview
Graphs consist of vertices (nodes) and edges (connections). They can be directed/undirected, weighted/unweighted, cyclic/acyclic.

## 🛠️ Common Patterns & Techniques
- Breadth-First Search (BFS) & Depth-First Search (DFS)
- Topological Sorting (Kahn's Algorithm, DFS)
- Disjoint Set Union (DSU) / Union-Find (Cycle detection, Connected Components)
- Shortest Path Algorithms (Dijkstra, Bellman-Ford, Floyd-Warshall)
- Minimum Spanning Tree (Kruskal's, Prim's)
