# Greedy

## 📌 Overview
Greedy algorithms build up a solution piece by piece, always choosing the next piece that offers the most immediate (local) benefit, hoping it leads to a global optimal solution.

## 🛠️ Common Patterns & Techniques
- Activity Selection / Interval Scheduling
- Fractional Knapsack
- Greedy Choice Property & Optimal Substructure Proofs
- Sorting-based Greedy Strategies
