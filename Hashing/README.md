# Hashing

## 📌 Overview
Hashing uses Hash Maps and Hash Sets to achieve constant-time \(O(1)\) average lookups, insertions, and deletions.

## 🛠️ Common Patterns & Techniques
- Frequency Counter (Element counts)
- Preserving Index mappings (e.g., Two Sum)
- Subarray Sum equals K (Prefix sum + Hash map)
- Set lookups for unique element tracking
