# Heap / Priority Queue

## 📌 Overview
A Heap is a specialized tree-based data structure satisfying heap properties (Min-Heap / Max-Heap), making fast retrieval of the minimum or maximum element possible in \(O(1)\) and insertion/deletion in \(O(\log N)\).

## 🛠️ Common Patterns & Techniques
- Kth Smallest / Largest Element
- Top-K Frequent Elements
- Two Heaps Pattern (Median in a Data Stream)
- K-Way Merge
