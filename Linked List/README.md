# Linked List

## 📌 Overview
A Linked List is a linear data structure where elements are connected via pointers. Variations include Singly, Doubly, and Circular Linked Lists.

## 🛠️ Common Patterns & Techniques
- Fast and Slow Pointers (Floyd's Cycle Finding, Middle of list)
- In-place Reversal (Iterative & Recursive)
- Dummy Head Pointer (Simplifying edge cases)
- Merging / Sorting Linked Lists
