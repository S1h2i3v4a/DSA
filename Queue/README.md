# Queue

## 📌 Overview
A Queue is a First-In, First-Out (FIFO) data structure. Variations include Double-Ended Queue (Deque) and Priority Queue.

## 🛠️ Common Patterns & Techniques
- Breadth-First Search (BFS) Traversal
- Monotonic Deque (Sliding Window Maximum)
- Circular Queue & Buffer implementations
