## 📚 Topics Overview

| # | Topic | Description |
|---|---|---|
| 1 | [Arrays](./Arrays/) | Array traversal, sub-arrays, prefix sums, and element manipulation. |
| 2 | [Strings](./Strings/) | String manipulation, pattern searching, anagrams, and palindromes. |
| 3 | [Hashing](./Hashing/) | Hash maps, hash sets, frequency counting, and fast lookups. |
| 4 | [Two Pointers](./Two Pointers/) | Optimization technique using multi-pointer traversals. |
| 5 | [Sliding Window](./Sliding Window/) | Subarray and substring problems using fixed/variable windows. |
| 6 | [Binary Search](./Binary Search/) | Divide and conquer searching on sorted arrays or search spaces. |
| 7 | [Linked List](./Linked List/) | Singly, doubly, and circular linked lists, reversals, and cycle detection. |
| 8 | [Stack](./Stack/) | LIFO operations, monotonic stacks, and expression evaluation. |
| 9 | [Queue](./Queue/) | FIFO operations, deques, and priority handling. |
| 10 | [Recursion](./Recursion/) | Subproblem decomposition, call stack mechanics, and base cases. |
| 11 | [Backtracking](./Backtracking/) | Exhaustive search, permutations, combinations, and N-Queens. |
| 12 | [Trees](./Trees/) | Binary trees, traversals (DFS/BFS), depth/height, and tree properties. |
| 13 | [BST](./BST/) | Binary Search Trees, search, insertion, deletion, and validation. |
| 14 | [Heap](./Heap/) | Priority Queues, Min-Heap, Max-Heap, and K-way problems. |
| 15 | [Graph](./Graph/) | Graphs, BFS/DFS, shortest paths, topological sort, MST, and Disjoint Set Union (DSU). |
| 16 | [Dynamic Programming](./Dynamic Programming/) | Memoization, tabulation, subproblems, state transitions, and optimization. |
| 17 | [Greedy](./Greedy/) | Local optimum choices leading to global solutions. |
| 18 | [Trie](./Trie/) | Prefix trees, dictionary lookups, and auto-complete algorithms. |
| 19 | [Bit Manipulation](./Bit Manipulation/) | Bitwise operations, XOR tricks, masks, and bit shifting. |
| 20 | [Math](./Math/) | Number theory, GCD/LCM, primes, modular arithmetic, and combinatorics. |
| 21 | [Miscellaneous](./Miscellaneous/) | Mixed/advanced problems, design problems, and unclassified topics. |
