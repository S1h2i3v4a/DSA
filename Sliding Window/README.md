# Sliding Window

## 📌 Overview
Sliding Window converts nested loops over continuous subarrays or substrings into single loops by maintaining a window boundary.

## 🛠️ Common Patterns & Techniques
- Fixed Size Window (Max sum subarray of size K)
- Dynamic Size Window (Longest substring with K distinct characters)
- Auxiliary Hash Map/Set to track elements within the current window
