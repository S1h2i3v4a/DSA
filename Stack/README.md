# Stack

## 📌 Overview
A Stack is a Last-In, First-Out (LIFO) data structure. It is extensively used in parsing, recursive call stack simulation, and monotonic properties.

## 🛠️ Common Patterns & Techniques
- Monotonic Stack (Next Greater / Smaller Element)
- Parentheses Matching & Expression Parsing
- Min Stack / Max Stack design
