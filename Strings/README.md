# Strings

## 📌 Overview
Strings are sequences of characters. Operations include pattern matching, string manipulation, anagram detection, and parsing.

## 🛠️ Common Patterns & Techniques
- Frequency Map / Array for character counts
- Sliding Window for substring problems
- Two Pointers (Palindrome checking, reversal)
- String Matching (KMP, Rabin-Karp, Z-Algorithm)
- Trie data structure for prefix searches
