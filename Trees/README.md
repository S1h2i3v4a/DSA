# Trees

## 📌 Overview
Trees are hierarchical non-linear data structures consisting of nodes connected by edges. Binary trees are the most common form in DSA.

## 🛠️ Common Patterns & Techniques
- DFS Traversals (Pre-order, In-order, Post-order)
- BFS Level-Order Traversal
- Subtree properties (Height, Depth, Diameter, Balance)
- Lowest Common Ancestor (LCA)
