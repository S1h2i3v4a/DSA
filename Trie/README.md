# Trie

## 📌 Overview
A Trie (Prefix Tree) is a tree-like data structure used to efficiently store and retrieve keys in a dataset of strings, commonly utilized for autocomplete and spell-checking.

## 🛠️ Common Patterns & Techniques
- TrieNode Structure (Children array/map, IsEndOfWord boolean flag)
- Fast Insertion and Search in \(O(L)\) where \(L\) is key length
- Prefix Matching / Auto-completion
- Bitwise Trie (Maximum XOR of two numbers in an array)
